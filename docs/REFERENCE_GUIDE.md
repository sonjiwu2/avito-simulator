# Visual Reference Guide

These five original generated references establish one intended game direction. They are concept artwork, not actual game captures, editable pixel source, a validated tileset or animation exports. Read ART_DIRECTION and ASSET_CONTRACT for production geometry; those specifications override inconsistent details inside the concepts.

| Image | Use | Do not copy literally |
|---|---|---|
| [Day office](reference-images/01-office-day.jpg) | Warm atmosphere, landmarks, areas and restrained HUD | Exact perspective, tiny text, every plant or fixed room coordinates |
| [Evening incident](reference-images/02-evening-incident.jpg) | Team scene, evening contrast, dialogue framing | A mandatory overtime incentive, unreadable miniature chart, arbitrary countdown wording |
| [Workstation](reference-images/03-workstation.jpg) | Evidence panel, task/chat hierarchy, office continuity | Baked text or assumption that a new profile alone proves fraud |
| [Character direction](reference-images/04-character-animation-direction.jpg) | Hero identity, four facings, action and expression vocabulary | Exact cell slicing, claimed anchor alignment or motion quality; this is a still board |
| [Environment direction](reference-images/05-environment-direction.jpg) | Material coherence, furniture variety, modular kit vocabulary | Background grid as tile geometry, inconsistent projection or generated labels |

Keep the warm atmosphere but simplify final sprites into purposeful native-resolution clusters. The character board is a direction guide: some walk poses may be insufficiently distinct, and front/back badge placement requires deliberate cleanup. Draw and verify actual cels rather than treating the reference row as a finished loop.

Full-resolution original PNGs are provided in the separate production pack. Optimized JPEG copies here are documentation only. Runtime pixel art must be lossless transparent PNG, produced independently and validated. Do not load these JPEGs into the playable office as scenery.
